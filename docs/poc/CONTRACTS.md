# Frozen contracts v1

Root-owned Shared/Models.swift and Emulator/CoreBridge/include/DuoCore.h define the ABI. Root alone edits Package.swift, App/, scripts/, Dependencies/, project/build configuration and shared headers.

- Swift sources in the app form one module (no DuoLogic import in app sources). Host SwiftPM DuoLogic includes Shared, Input, Persistence, DisplayEnvironment and Library; UIKit-only code must be guarded with `#if canImport(UIKit)`.
- DSFrame is an owned BGRA8 256×384 buffer: logical top screen rows 0–191, logical lower rows 192–383. Layout swap changes destinations only. DSInput native touch is x 0–255/y 0–191; bridge translates to the verified core pointer convention.
- One process-wide runtime and one serial executor own core lifecycle/run/save. Audio has a bounded SPSC ring, no callback allocation/locking; core shutdown quiesces consumer before freeing. Core frame bytes copied before next run.
- GameRecord.id is full content SHA256. LibraryStore(root: URL) offers importROM(from:), list(), romURL(for:), gameDirectory(for:), delete(_:). These can throw. PersistenceStore(root: URL) offers writeBattery(_:gameID:), readBattery(gameID:), saveState(_:gameID:coreVersion:), loadState(gameID:coreVersion:). Version/checksum errors must preserve battery saves. Root coordinates calls on serial runtime executor.
- P3 owns DisplayEnvironment/LayoutSolution/ScreenLayoutSolver and InputRouter APIs; document exact public interface for root integration. PlaySessionView must consume frame, callbacks, geometry/input and not own a core or advance frames. Metal presentation may be provided in P3 Features/PlaySession to avoid ownership collision with P2 Video buffer code.
- P2 owns EmulationSession API; provide async boot/pause/resume/stop, input updates, lid toggle, state operations and published copied frame/phase/error for root integration. Session may use Foundation/Combine on iOS; deterministic portable helpers/test harness should be isolated.
- Audio target uses core-reported FPS/sample rate; bounded audio lead and monotonic pacing, never display ticks. Explicit interruption policy pauses and clears audio/input. No system callback required for sole persistence: checkpoint/pause/explicit stop flush.
- Build: root generates Xcode project from source files with scripts/generate-project.py. Swift 5 mode, iOS 17 minimum; DEVELOPER_DIR=/Applications/Xcode-Beta.app/Contents/Developer. C++17. Static core source path build/dependencies/melonds-ds at bc4e4b67d2d470d7c682810a1e892cafd6f9082b. Root supplies libretro headers and linked static archives. Workers do not edit dependency source/build files.
